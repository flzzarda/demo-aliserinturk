# Adana Kebapçı Ali Serintürk — Web Sitesi Ön İzlemesi

Bu, işletmeye sunulmak üzere hazırlanmış statik ve mobil uyumlu web sitesi demosudur.

## Açma

1. ZIP dosyasını klasöre çıkarın.
2. `index.html` dosyasına çift tıklayın.
3. Site tarayıcıda açılır. Sunucu veya paket kurulumu gerekmez.

## İçerik

- Responsive tek sayfa tasarım
- Mobil navigasyon
- Telefon arama bağlantıları
- WhatsApp bağlantısı
- Google Maps arama bağlantısı
- Yerel görsel dosyası (`assets/kebap-hero.png`)
- Menü/fiyat/çalışma saati gibi teyit gerektiren içeriklerde açık demo notları

## Yayın öncesinde işletme sahibinden teyit edilmesi gerekenler

- Resmî işletme adı ve adres yazımı
- Güncel telefon ve WhatsApp numarası
- Güncel menü, ürün adları ve fiyatlar
- Çalışma saatleri ve paket servis koşulları
- İşletmeye ait gerçek fotoğraflar ve varsa logo
- Resmî Instagram hesabı ve doğru harita konumu

Hero ve hikâye bölümündeki kebap fotoğrafı temsilî tanıtım görselidir; işletmenin kendi yemeğinin fotoğrafı olarak sunulmamalıdır.
